# LINE 圖文選單設定文字

圖片檔：`line-rich-menu-three-2500x843.jpg`

建議模板：橫幅 3 格，1 排 3 欄。

## 點擊區域

### 1. 代購流程

座標：`x=0, y=0, width=833, height=843`

點擊後送出的文字：`代購流程`

自動回覆內容：

您好，代購流程如下：

1. 先私訊您想要的商品連結或圖片
2. 確認商品尺寸、款式、色號、數量（商品價格皆包含國際運費，滿2000免賣貨便運費38）
3. 確認後先支付商品金額 50% 作為訂金
4.  收到訂金後安排登記採買
5.  餘款賣貨便貨到付款

### 2. 出貨時間

座標：`x=833, y=0, width=834, height=843`

點擊後送出的文字：`出貨時間`

自動回覆內容：

出貨時間如下：

1. 每個月會安排 2 次從日本寄出
2. 確切寄出日期會依集貨、商品到齊狀況另行通知
3. 貨物到達台灣後，通常會在 2～3 天內安排賣貨便寄出
4. 寄出後請留意賣貨便取貨通知，並於期限內完成取貨

### 3. IG 連結

座標：`x=1667, y=0, width=833, height=843`

點擊動作建議：開啟網址

網址：請填入您的 Instagram 連結，例如 `https://www.instagram.com/您的帳號/`

如果 LINE 後台選擇「發送訊息」而不是「開啟網址」，可使用：

點擊後送出的文字：`IG 連結`

自動回覆內容：

歡迎到我們的 Instagram 查看更多商品與最新資訊：

請點這裡：
https://www.instagram.com/您的帳號/
